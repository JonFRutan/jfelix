                <h3 class="center">Virginia Spaceport Authority</h3>
                <p>During the Summer of 2025 I interned at the Virginia Spaceport Authority (VSA) as an IT/IS Intern. I worked primarily with the system administrator (Brian Bishop) and network engineer (John Phillips). At the beginning of my internship the VSA began to reintroduce Linux (RHEL) into their tech environment, which provided an opportunity for me to use some of my preexisting knowledge to help.</p>
            </div>

            <div class="port-list">
                <div class="port-entry">
                    <div class="port-entry-body">
                        <h3>RHEL Integration</h3>
                        <div class="port-desc">
                            <p>The VSA has to meet higher than usual security standards due to it's industry and position within the government. Standards like NIST must be met on deployed machines, and enhancing general security and auditing practices is just good housekeeping on our machines.</p>
                            <p>I wrote a set of scripts to expedite the set up process and provide enhanced security on our machines</p>
                            <ul>
                                <li><b>VM_SETUP</b> - Script that ran all the other scripts for quick VM setups (similar to a Makefile).</li>
                                <li><b>OVAL_SCAN</b> - Script for automating and logging <a href="https://oval.mitre.org/">OVAL</a> vulnerability scans.</li>
                                <li><b>SSH_AUDIT</b> - Script for auditing SSH connections tracking login count, login times and IPs.</li>
                                <li><b>ARCTIC_WOLF</b> - Enrolls and sets up SOC service <i>ArcticWolf</i>.</li>
                                <li><b>REPO_ACCESS</b> - Script for enabling <a href="https://docs.fedoraproject.org/en-US/epel/">EPEL</a> on RHEL machines.</li>
                            </ul>
                            <p><i>No Public Repository, Sorry</i></p>
                        </div>
                    </div>
                </div>

                <div class="port-entry">
                    <div class="port-entry-body">
                        <h3>CardDAV Server/Software</h3>
                        <div class="port-desc">
                            <p>I was tasked with deploying a list of all VSA employees' contact information on everyone's phones within the company.</p>
                            <p>I used three open source projects to accomplish this: PostgreSQL, Radicale, and NGINX.</p>
                            <p>I combined all of these by building Python tools for generating vCards, managing the database (psycopg2), and updating the Radicale server.</p>
                            <p>It also includes a Flask frontend for managing all these systems with a GUI.</p>
                            <p><i>No Public Repository, Sorry</i></p>
                        </div>
                    </div>
                </div>

                <div class="port-entry">
                    <div class="port-entry-body">
                        <h3>CACTI Server</h3>
                        <div class="port-desc">
                            <p><a href="https://www.cacti.net/">Cacti</a> is a network fault monitoring and data visualization tool.</p>
                            <p>Using a Rocky Linux VM in our cluster (ran out of RHEL licences), I set up and installed Cacti so that we could monitor the devices on our network using SNMP.</p>
                            <p>Using this tool, we are able to track and monitor our core switches, down to individual interfaces.</p>
                            <p><i>No Public Repository, Sorry</i></p>
                        </div>
