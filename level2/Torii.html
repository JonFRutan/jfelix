Matrix

matrix.jfelix.space »

Matrix » / Element » instance.
Federated Slack/Discord alternative with encrypted communications and file hosting. Registration is disabled, contact me if you want an account.

We are not currently federating to other instances.

Music

music.jfelix.space »

A public facing side of my radio project. This one serves as a frontend to different university radio stations.
Uses Butterchurn for visualizations and a UI for tuning to different stations.

Publicly accessible, send me a message if you want any stations added.

Radio

radio.jfelix.space »

Icecast 2 » server livestreaming radio stations. The impetus to design a new broadcast generation software (wip).
Utilizes Butterchurn for live audiovisualizations to my broadcasts.
