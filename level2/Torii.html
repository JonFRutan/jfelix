Radio

radio.jfelix.space »

Icecast 2 » server livestreaming radio stations using Liquidsoap. Integrated with Navidrome for both radio streaming and audio-syncing. Has a built-in visualizer inspired by Milkdrop called Butterchurn. Not publicly accessible, contact me for details.

Music

music.jfelix.space »

A public facing side of my radio project. This one serves as a frontend to different university radio stations.
Uses Butterchurn for visualizations and a UI for tuning to different stations.

Publicly accessible, send me a message if you want any stations added.

GAOL

gaol.jfelix.space »

GAOL is a multiplayer AI storyteller. It utilizes the Gemini API and a novel RAG system in order to create a smooth storytelling experience. It supports up to 6-players and has highly dynamic world and character development.

OpenValve

valve.jfelix.space »

OpenValve is the reincarnation of a database class project. Developed alongside *Trevor Corcoran*, it is a frontend for a Steam game database, Steam APIs, and contains data visualizations and data analysis tools.

Orbital

orbit.jfelix.space »

Orbital is a simple, pleasant webapp that turns strings of characters into melodies. Use it to create custom sound systems, and share them with others.
